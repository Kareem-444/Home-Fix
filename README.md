# Servicely

Servicely is a modern web application for booking trusted local services, built with React, TypeScript, Vite, and Tailwind CSS. It features a clean UI, dark mode, and user authentication. Users can browse providers, manage bookings, save favorites, and contact support.

## Project Structure & Channels

- **Frontend:** React (TypeScript), Vite
- **Styling:** Tailwind CSS (with dark mode)
- **Routing:** React Router
- **Icons:** Lucide React
- **State & Hooks:** React hooks
- **Linting:** ESLint (with recommended configs)
- **Pages:**
  - Landing
  - Browse
  - Provider Profile
  - User Dashboard
  - Provider Dashboard
  - Sign In / Register / Forgot Password
  - About
  - Privacy Policy
  - Terms of Service
  - FAQ
  - Careers
  - Contact
  - Help Center
  - Not Found (404)
- **Components:**
  - Navbar (with dark mode toggle)
  - Footer
  - Accordion, Button, Dropdown, EmptyState, FilterBar, Loader, Modal, RatingStars, ServiceCard, Tabs, Toast
- **Assets:** SVGs, images, mock data (JSON)

## How It Works

Users can sign up, log in, browse and book services, view provider profiles, save favorites, and contact support. The site supports light and dark themes, responsive layouts, and smooth navigation.

## Getting Started

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Visit [http://localhost:5173](http://localhost:5173)

## Channels Used

- **React**: UI and state management
- **React Router**: Page navigation
- **Tailwind CSS**: Styling and dark mode
- **Lucide React**: Icon library
- **ESLint**: Code linting
- **Vite**: Build tool
